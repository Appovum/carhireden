Highlights

The features that matter most

Live Network Sync
Connect Awin or CJ Affiliate, run one sync, and your site populates with live offers. Programmes become stores, promotions become coupons, and transactions become attributed commissions.
Earnings Dashboard
Real commission data pulled from your networks. See clicks, conversions, EPC, and commission broken down by store, coupon, category, and day. Know which coupon actually paid you.
Click Attribution
Every outbound click is tagged with a unique SubID. When the network reports a commission, it maps back to one coupon and one user. Bot filtering, two link strategies, and transaction deduplication included.
Cashback Wallets
Append-only ledger architecture. Balances are derived, never overwritten. Pending → confirmed → paid lifecycle. Missing-cashback claims, withdrawal approvals, and referral bonuses.
Self-Serve Ad Sales
Brands pick a placement, pay by card or PayPal, upload artwork through their own portal. Signature-verified webhooks, automatic campaign expiry, and performance tracking.
Feed Normalization
Real affiliate feeds are messy. CouponPilot extracts prices from titles, parses coupon codes, normalizes discounts, strips tracking params, and deduplicates — automatically.
Security First
AES-256-GCM encryption at rest, session-based auth with Google OAuth, CSRF protection, rate limiting on all sensitive endpoints, Zod validation, and IP hashing.
SEO Infrastructure
Dynamic sitemaps, JSON-LD structured data, meta templates with variables, programmatic routes, on-demand ISR, and evergreen expired-coupon pages that keep ranking.
Docker Ready
Production Dockerfile with multi-stage build and docker-compose.yml. One command deploys the app and PostgreSQL 16. Also supports Vercel and any Node.js host.

Connector Architecture

The NetworkConnector interface standardizes all affiliate network integrations. Two connectors ship in v1.0.0:

  • Awin — Template-based link builder with programmes, promotions, and transaction sync
  • CJ Affiliate — Append-subid link strategy with advertisers, link search, and commission detail

Adding a new network requires implementing a single file — no changes anywhere else. Recorded test fixtures are included for development without live credentials.

For Future Updates

Upgrade path

When future versions are released, follow this process to safely update without losing your data or media files:

Back up your database and environment

Always create a database dump (pg_dump) and back up your .env file before starting an update.

Safe to overwrite vs. DO NOT overwrite

Safe to replace: src/, prisma/schema.prisma, package.json, package-lock.json, Dockerfile, docker-compose.yml.
DO NOT overwrite: .env, public/uploads/ (uploaded store logos, ad artwork & avatars), or your PostgreSQL database storage.

Run database migrations

Execute npx prisma db push to apply schema updates to your database.

Rebuild and restart

Run npm run build && npm start or docker compose up -d --build.

Verify application health

Check the admin dashboard, test a store link, and verify network sync status.

Never overwrite public/uploads/ or .env when upgrading. User-uploaded logos, ad creative images, and master encryption keys live in these locations.
