03 — Installation

Three ways to deploy. Pick one.

Docker for VPS, one-click for Vercel, or manual for anything else.

Option A — Docker Compose Recommended

One command spins up the app and PostgreSQL together.

Step 1 — Clone the repository

Bash
git clone <your-repo-url> couponpilot
cd couponpilot

Step 2 — Configure environment

Bash
cp .env.example .env
# Edit .env — set APP_SECRET and NEXT_PUBLIC_APP_URL

Never share your APP_SECRET. All sensitive data (network API keys, payout details) is encrypted with this key using AES-256-GCM. Losing it means losing access to encrypted data.

Step 3 — Launch

Bash
docker compose up -d --build

This starts the app on port 3000 and PostgreSQL 16 on port 5432.

Step 4 — Initialize database

Bash
docker compose exec app npx prisma db push
docker compose exec app npx prisma db seed

Step 5 — Open the installer

Navigate to http://your-server-ip:3000/install in your browser.

Option B — Vercel + Managed Postgres

Step 1 — Create a database

Sign up for Neon or Supabase and create a PostgreSQL database. Copy the connection string.

Step 2 — Deploy to Vercel

Import the codebase into Vercel and set these environment variables:

VariableValue
DATABASE_URLYour PostgreSQL connection string
APP_SECRETA random 32+ character string
NEXT_PUBLIC_APP_URLYour Vercel domain URL
CRON_SECRETA random bearer token

Step 3 — Initialize database

Bash
npx prisma db push

Step 4 — Run the installer

Navigate to https://your-app.vercel.app/install

Option C — Manual Node.js

Bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env

# 3. Generate Prisma client & push schema
npx prisma generate
npx prisma db push

# 4. Seed demo data (optional)
npx prisma db seed

# 5. Build and start
npm run build
npm start

Then open http://localhost:3000/install to complete setup.

Demo Mode & Read-Only Protection Live Preview Mode

CouponPilot includes a built-in read-only Demo Mode to protect live preview deployments (such as CodeCanyon live demos) from public tampering, record deletion, or unwanted database modifications.

VariableDescriptionDefault / Example
NEXT_PUBLIC_DEMO_MODESet true to enable public preview read-only protection. Set false for full production/local CRUD operations.false
DEMO_MODEServer-side override flag for Demo Mode read-only protection.false
How Demo Mode Operates:
  • Edge Middleware Guard: When NEXT_PUBLIC_DEMO_MODE=true, all write operations (POST, PUT, DELETE) on /api/admin/* and /api/account/* endpoints are intercepted at the edge middleware level with an HTTP 403 Forbidden response.
  • Brand-Aligned Toast Notifications: Any attempted administrative edit, creation, or deletion triggers a sleek black & white Demo Mode Toast Notification ([DEMO MODE] Modifications are disabled in public live preview mode.).
  • Dynamic Sidebar Badge: The Admin Sidebar dynamically displays a DEMO_MODE badge when active, and automatically switches to DEVELOPMENT or PRODUCTION when disabled.
  • Disabling Demo Mode: For your own live site deployment, set NEXT_PUBLIC_DEMO_MODE=false in .env or .env.local to grant full admin CRUD privileges.

21 — Custom Networks

Adding a new network is a one-file job.

CouponPilot's connector architecture is designed for extensibility. Each network implements a standardized interface — no changes needed outside its own file.

TypeScript
interface NetworkConnector {
  slug: string;
  name: string;

  testCredentials(credentials): Promise<{ success; message? }>;
  fetchStores?(credentials, options?): Promise<NormalizedStore[]>;
  fetchOffers(credentials, options?): Promise<NormalizedOffer[]>;
  fetchConversions(credentials, since, options?): Promise<NormalizedConversion[]>;
  mapToCoupon(offer, storeId): CouponInput;
}

To add a new network

  1. Create src/lib/connectors/yournetwork.ts
  2. Implement the NetworkConnector interface
  3. Register it in src/lib/connectors/registry.ts
  4. Done — the import engine picks it up automatically

We provide recorded test fixtures for every connector so you can develop and test without live API credentials.

22 — Click Attribution

Every click carries its own fingerprint.

Outbound links are cloaked and tagged with a unique SubID before they leave your site — so when the commission posts, it maps back to one coupon and one user.

Step 1
Visitor clicks
/go/clk_8f2a…
→
Step 2
Network logs it
sid=clk_8f2a…
→
Step 3
Commission posts
matched to click
→
Step 4
Ledger credited
+$12.48

How the redirect works

  1. Click is logged — A Click row is created with coupon, store, user, IP hash, user agent, referrer, device, and bot score
  2. SubID is generated — The click ID becomes the SubID passed to the network
  3. Deep link is built — Network link template is interpolated with your credentials and the SubID
  4. 302 redirect — Never 301, because every click must be logged

Link Strategies

StrategyUsed ByHow It Works
templateAwinFull URL template with placeholder interpolation
append_subidCJAppends &sid={subId} to a pre-built click URL

Bot Filtering

  • User-agent detection — Known bot strings are blocked before logging
  • Rate limiting — Per IP hash to prevent click fraud
  • Bot score — Multi-signal calculation for each click

Anonymous click claiming: Users who click before signing up get an anon_id cookie. When they create an account, all anonymous clicks are retroactively attributed to their account.

23 — Cashback Engine

Cashback your users can actually trust.

An append-only ledger, not a running total. Balances are derived, never overwritten — so nothing silently disappears when a merchant declines an order.

Ledger Entry Types

Entry TypeEffect
cashback_pending+amount to pending bucket
cashback_confirmed+amount to confirmed bucket

withdrawal_requestedRecords intent to withdraw

Financial integrity: All money is stored as integers in minor units (cents/paise) with an explicit currency code. Never floats. Balances are always derived by summing the ledger, cached with invalidation on write.

32 — Security

Defense in depth.

Session-based auth, AES-256-GCM encryption at rest, Zod validation on every endpoint, and configurable rate limiting.

Authentication

  • Secure, HTTP-only session cookies (cp_session)
  • Google OAuth integration for social login
  • Email verification required for cashback features
  • Password reset via secure token emails
  • Session rotation on login

Encryption at Rest

  • Network API credentials — AES-256-GCM
  • User payout details (bank accounts, PayPal) — AES-256-GCM
  • All settings marked as encrypted — AES-256-GCM
  • Master key (APP_SECRET) — Never stored in database

Demo Mode Read-Only Protection

  • Edge middleware protection intercepting write operations (POST, PUT, DELETE) when NEXT_PUBLIC_DEMO_MODE=true.
  • Prevents public preview visitors from deleting or altering database records.
  • Displays real-time black & white [DEMO MODE] Toast notifications on blocked operations.

36 — Troubleshooting

Common issues and fixes.

Quick solutions for the most frequently encountered problems and integration gotchas.

Redirect URL contains literal {merchantId} or {affiliate_id}?

The store's network merchant ID is missing in Admin → Stores, or your network affiliate ID is not set in Admin → Networks. Update these fields and click the store's Test Link button in Admin → Stores to check the generated URL before going live.

Coupons import with no promo code (deals only)?

You are not joined to that advertiser's programme on the affiliate network. Networks hide coupon codes from unjoined publishers, so offers import as link-only deals. Join the advertiser's programme in your Awin or CJ dashboard, wait for approval, and re-run the sync from Admin → Import Sources.

CJ Link Search returns 0 results?

Your website PID (Promotional Property ID) is not configured in CouponPilot settings. (Note that CJ operates two portals: API Personal Access Tokens live on developers.cj.com, while Promotional Properties live on the publisher dashboard at members.cj.com → Account → Websites / Promotional Properties). Copy your Property ID from members.cj.com and enter it in Admin → Networks → CJ → Property ID (PID).

"Database connection failed"

Invalid DATABASE_URL in .env. For Docker, ensure the database container is running: docker compose ps

"APP_SECRET is required"

Set a random 32+ character string in your .env file.

"Prisma client not generated"

Run npx prisma generate before npm run build. The included build script handles this automatically.

"Cashback not appearing for users"

Ensure the conversion sync cron job is running. Check for unattributed conversions in Admin → Earnings. Verify SubID is passed correctly.

"Stripe webhook failing"

Verify STRIPE_WEBHOOK_SECRET matches your Stripe dashboard. Webhook URL must point to /api/webhooks/stripe.

Build fails on Vercel?

Ensure all required variables (DATABASE_URL, APP_SECRET, NEXT_PUBLIC_APP_URL) are set in Vercel's environment settings. CouponPilot includes fallback data providers to prevent 500 errors during build.

Debugging Tips

  • Check Admin → Audit Log for detailed action history
  • Review Import Source → Run History for sync errors
  • Check browser developer console for client-side errors
  • Docker logs: docker compose logs -f app
