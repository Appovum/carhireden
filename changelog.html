Changelog

A detailed record of every feature, fix, and improvement across all CouponPilot releases. We follow Semantic Versioning.

1.0.0 2026-08-04 Latest Release
Added
  • Project foundation — Next.js 16 App Router with TypeScript, Tailwind CSS 4, and Prisma ORM.
  • Referral bonus system — Automated configurable referral bonus (default $5) for referrers when their referred user's first cashback confirms. Enhanced referral code matching during signup.
  • Store deletion & bulk actions — Full CRUD with bulk activate, deactivate, and delete across all admin dashboards. Universal ConfirmModal component.
  • Advertiser portal — Comprehensive portal with payment tracking, campaign management (Awaiting Creative → Pending Review → Scheduled → Live → Completed), and automated approval workflows.
  • Admin modules — Alerts, referrals, custom pages, and public contact form with API support. Complete admin coverage for every entity type.
  • Middleware authentication — Edge-based auth protection for /admin, /account, /wallet, /withdraw, and all admin API routes.
  • Network sync APIs — Live Awin and CJ Affiliate connectors with fetchOffers(), fetchConversions(since), testCredentials(), and mapToCoupon().
  • Ad banner system — Header, sidebar, in-feed, and store page ad slots with image, AdSense, and custom HTML creatives. Impression and click tracking with CTR.
  • Cashback ledger — Append-only wallet with cashback_pending, cashback_confirmed, cashback_declined, withdrawal_*, referral_bonus, and adjustment entry types.
  • Click attribution — /go/[clickId] redirect route with SubID tracking, bot filtering, dual link strategies (template + append_subid), and anonymous click claiming.
  • Feed normalization — Discount parser, code extraction, category normalizer, merchant mapper, logo processor, deduplication, and per-store diversity caps.
  • Payment gateways — Stripe and PayPal integration with signature-verified webhooks for ad sales and featured placements.
  • SEO infrastructure — Dynamic sitemap, JSON-LD (Offer, AggregateRating, FAQPage, BreadcrumbList, Organization), meta templates with variables, and on-demand ISR revalidation.
  • Notification system — Email adapter layer (SMTP, Brevo, Resend), Telegram channel poster, weekly digest, and transactional email templates.
  • Security — AES-256-GCM encryption at rest, CSRF protection, rate limiting (login, vote, claim, withdrawal, redirect), Zod schema validation, and IP hashing.
  • GDPR compliance — Data export, account deletion, cookie consent gate, and editable affiliate disclosure component.
  • Docker deployment — Production Dockerfile with multi-stage build and docker-compose.yml with PostgreSQL 16.
  • Web installer — Guided setup wizard at /install for database configuration, admin account creation, and initial branding.
  • Sample dataset — Sample dataset with stores, coupons, categories, and ad creatives for immediate demo readiness.
  • Dark mode — System-aware toggle with localStorage persistence, affecting all public and admin pages.
  • Audit logging — Complete admin action trail with actor, action, resource, before/after diff, and IP address.
  • i18n support — Full internationalization string manager with export/import capabilities.
Changed
  • Payout configurations — Transitioned to dynamic payout configs with improved wallet balance calculation accuracy using ledger summation.
  • Withdrawal workflow — Moved from inline withdrawal requests to a dedicated withdrawal page with form, pending status management, and admin approval flow.
  • Loading states — Consolidated all admin page loading into AdminTable component with global loading component.
  • Alert query optimization — Optimized claim submission UI with real-time updates and refined input validation using Zod schemas.
  • App shell architecture — Implemented AppShell component, removed redundant Header/Footer from individual route pages for consistent layout.
  • Store logos — Updated StoreLogo with domain-based favicon auto-fetching. Redesigned navigation with category overflow menu.
  • Ad banner styling — Standardized all ad banner and category header styling using theme-based design tokens.
  • Admin panel redesign — Complete visual overhaul with SVG line icons, sentence case titles, neutral sparklines, 90-day organic analytics charts, and real brand dataset.
  • Dashboard density — Improved information density with dynamic period metric cards, sorted action queues, and activity feed.
Fixed
  • Decoded HTML entities in category names within header navigation.
  • Resolved Prisma type mismatch in bulk operations, updated build script to generate Prisma client before build.
  • Added robust fallback data provider and try-catch guards to eliminate 500 errors on Vercel deployments.
  • Resolved Vercel build error by providing fallback DATABASE_URL and sitemap try-catch guard.
  • Restored sign out button and created distinct collapse bar in sidebar footer.
  • Calibrated urgent badge threshold, corrected sidebar sentence case, fixed neutral sparkline colors and import labels.
  • Fixed real brand dataset variance, dual-axis chart rendering, restrained green styling, and math calculation errors.
Security
  • All network API credentials encrypted at rest with AES-256-GCM using the APP_SECRET master key.
  • User payout details (bank accounts, PayPal emails) encrypted at rest.
  • Session cookies set as HTTP-only, secure, with SameSite=Lax.
  • Rate limiting implemented on all sensitive endpoints (login, voting, claims, withdrawals, redirects).
  • CSRF token validation on all mutation endpoints.
  • Bot detection and filtering on the click redirect route.
  • IP addresses stored as SHA-256 hashes, never raw values.
